# هوبا بديل سيري (النسخة 1.1)

مساعد صوتي لأندرويد (9 وأعلى) بيتحكم في التليفون بالكلام، بأوامر عربي مصري أو إنجليزي.
المشروع مكتوب من الصفر بـ Kotlin.

## إزاي تطلّع ملف APK (GitHub)
1. ارفع محتوى فولدر `Hoba` على الـ repository (Add file ← Upload files)، والملفات الموجودة هتتبدّل.
2. تبويب **Actions** ← استنى **Build APK** يخلص ✅ ← نزّل **Hoba-APK** من تحت.
3. فك الضغط وثبّت `app-debug.apk`.

> **مهم في أول تحديث بس:** امسح النسخة القديمة من التليفون الأول، لأن توقيع النسخة الجديدة مختلف. بعد كده كل التحديثات هتتثبت فوق بعض عادي.

## الإعداد على التليفون (مرة واحدة)
1. إذن الميكروفون.
2. إذن الاتصال وجهات الاتصال.
3. **إذن العرض فوق التطبيقات** (ضروري عشان هوبا يقدر يفتح التطبيقات ويتصل).
4. تفعيل خدمة هوبا من إمكانية الوصول. لو الزرار رمادي: إعدادات ← التطبيقات ← هوبا ← ⋮ ← **السماح بالإعدادات المقيّدة**.
5. إعدادات التطبيق ← البطارية ← اسمح بالتشغيل في الخلفية (مهم على ريلمي).

## الاستخدام
زرار 🎤 عايم: **اسحبه** لأي مكان، ضغطة = أمر واحد، ضغطة طويلة = استماع مستمر. شريط صغير فوق بيوريك اللي سمعه.

### الأوامر
- افتح واتساب / افتح الكاميرا
- ارجع / الرئيسية / التطبيقات الاخيرة / الاشعارات
- انزل / اطلع
- اضغط على [اسم الزرار] — أو: اظهر الارقام ← اضغط 5
- اكتب [نص] / امسح
- **املا [اسم]**: بيكتب معلومة محفوظة (زي الاسم أو الرقم أو الإيميل). بتحفظها من شاشة التطبيق، سطر لكل معلومة: `الاسم: أحمد محمد`
- اتصل بـ [اسم]
- **ابعت واتساب لـ [اسم] وقوله [الرسالة]** — بيفتح الشات ويدوس إرسال
- ابعت رسالة لـ [اسم] وقوله [الرسالة] — SMS
- اقفل الشاشة / صحي الشاشة / افتح القفل
- صور الشاشة / ارفع الصوت / وطي الصوت

## حدود لازم تعرفها
- فتح القفل: أندرويد مش بيسمح لأي تطبيق يدخل البصمة أو الرقم السري بدالك. "افتح القفل" بتصحّي الشاشة وتسحب لفوق، وده بيكفي بس لو التليفون من غير رقم سري.
- التعرف على الصوت بيتم عن طريق خدمة التليفون (غالبًا جوجل).
- تغيير سطوع الشاشة مش موجود.
